# Development Guidelines

- You manage this Git repository yourself, including `.gitignore`.
- Do not write too many safety checks.
- Do not maintain the two standard project-local skills mentioned in the global `AGENTS.md`.
- Project-local skills should be brief.
- If you are the main agent, you should not implement features or fix bugs yourself. Instead, you should assign work to proper subagents. Reuse existing subagents if their previous work / contexts match the incoming task. The main agent should focus on planning and validation.
